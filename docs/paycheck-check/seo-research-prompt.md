# Research Areas

Determine current guidance for:

## 1. Crawlability and Indexing

Research:

- crawlability
- indexability
- HTTP status behavior
- authenticated/private content
- `noindex`
- robots.txt limitations
- accidental indexing of private pages
- login-required pages

Clearly distinguish crawl control from indexing control.

## 2. robots.txt

Determine:

- what belongs in robots.txt;
- what should not be placed there;
- whether private authenticated routes should also use appropriate page/header-level noindex behavior;
- whether robots.txt should be used to hide sensitive information.

Do not assume robots.txt is a security mechanism.

## 3. XML Sitemap

Determine:

- whether Paycheck Check needs an XML sitemap;
- what URLs should be included;
- whether authenticated/private pages should be excluded;
- sitemap size/format considerations;
- whether a Laravel implementation needs a package or can use existing application functionality.

Do not recommend a package unless explicitly approved.

## 4. Canonical URLs

Research:

- canonical link behavior;
- duplicate URL handling;
- query-string variants;
- trailing-slash consistency;
- public page canonical strategy.

## 5. Titles and Meta Descriptions

Research current best practices for:

- unique page titles;
- useful meta descriptions;
- avoiding duplication;
- appropriate length guidance;
- whether search engines may rewrite titles/snippets.

Do not treat recommended character counts as hard requirements unless an authoritative source establishes them.

## 6. Headings and Content Structure

Research:

- one clear primary page topic;
- heading hierarchy;
- semantic HTML;
- useful page content;
- avoiding thin/duplicated public pages.

## 7. Structured Data

Determine which structured-data types, if any, are appropriate for Paycheck Check's public pages.

Do not add structured data merely because it exists.

Identify:
- appropriate schema types;
- required/recommended properties;
- validation considerations;
- whether structured data could create misleading search results.

## 8. Mobile and Performance

Research:

- mobile-first indexing;
- Core Web Vitals;
- performance considerations relevant to Laravel + Inertia React;
- responsive behavior;
- useful performance metrics.

Distinguish ranking/search requirements from general engineering best practices.

## 9. Social Metadata

Research:

- Open Graph;
- relevant social sharing metadata;
- Twitter/X card metadata if still applicable;
- image/title/description requirements.

Treat social metadata separately from search-engine ranking requirements.

## 10. Duplicate and Thin Content

Determine current guidance for:

- duplicate public pages;
- parameterized variants;
- thin pages;
- autogenerated pages;
- canonical/noindex choices.

## 11. Authenticated/Private Pages

Provide explicit recommendations for:

- dashboard
- job settings
- time entry
- paycheck calculations
- actual-pay comparisons
- tax/deduction information
- annual summaries
- monthly reports

These pages contain private financial information and should not be public search content.

Explain the correct architectural/indexability approach without weakening authentication or authorization.
